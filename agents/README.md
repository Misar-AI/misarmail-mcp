# MisarMail agents

Task-scoped agents built on the @misarmail/mcp MCP server. Each bundles a subset
of the tools with the rules for using them safely.

| Agent | Purpose |
| --- | --- |
| `email-campaign-manager` | Plans, drafts, A/B tests and sends campaigns, checking deliverability and warm-up capacity before any send. |
| `deliverability-doctor` | Diagnoses inbox placement: score, SPF/DKIM/DMARC, warm-up ceiling, list hygiene — returns a prioritized fix list. |
| `inbox-triage` | Triages the unified inbox: categorises intent, drafts replies, escalates what needs a human. |

All of them require authentication — see https://docs.misar.io/mail/mcp. Generated by
`scripts/mcp/generate-distribution.mjs`; edit the product entry, not these files.
